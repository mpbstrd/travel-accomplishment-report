Welcome to the Signature Workflow Testing UI

This interface allows you to manually test all signature workflow APIs without writing code.

📋 Available Test Scenarios

  • report-001: Completed workflow with all 3 signatures
  • report-002: Draft workflow (incomplete report)
  • report-003: Pending Branch Acknowledgement (1 signature completed)

👥 Test Users

  • user-001: John Doe (Branch Manager)
  • user-002: Jane Smith (Branch Staff - Preparer)
  • user-003: Bob Johnson (NISD Staff)

🔧 Quick Start

  1. Make sure the API server is running (npm run dev)
  2. Make sure the database is seeded (npm run seed)
  3. Use the navigation menu to access different testing features
  4. Check the browser console for detailed API responses

⚠️ Mock Mode

This testing environment uses mock implementations for external services (User Management, Report Management, Notification Service). Set USE_MOCK_SERVICES=true in your .env file.
